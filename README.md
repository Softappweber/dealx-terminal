# TradeX Terminal

Fast Web Trading Terminal for FYERS API

## Setup

1. Copy `.env.example` to `.env` and fill FYERS credentials
2. Run `npm install`
3. Run `npm start`
4. Open http://localhost:3000

## Features

- FYERS OAuth Login
- Live Watchlist
- Real-time Charts (TradingView)
- Order Placement (Buy/Sell)
- Positions Tracking
- Orders List
- WebSocket Live Data

## Tech Stack

- HTML/CSS/JS (Vanilla)
- Node.js + Express
- FYERS API v3
- TradingView Widget

## Deploy

- Vercel: `vercel --prod`
- Railway: Connect GitHub repo
- Render: Deploy as web service
